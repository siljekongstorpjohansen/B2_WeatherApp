## Final reflection
When working with this project we wanted to learn from the positives and negatives from the N-back project. Creating a clear SPEC file as the first part of this project gave clear guidelines and a plan for both us and the AI to follow. The workflow was more structured and the promts for the AI was easier to write and the AI gave more accurate code at the first try. The AI also knew to add handlers for user interactions right away so running the code and testing it on the fun ran smoothly right away. 

To get a more structured code the AI were given instructions multiple times to clean up the code and use "refactory". Earlier experience says that the AI often gives long code with unneccesary many functions and variables at times. Cleaning up the code makes it more readable and easier to follow and keep working on. 

The part of the code we are the most satisfied with is the structure of the code. A resualt of structural work and clear prompts to the AI to keep the code structured and easy to read. This also made it easier to step by step add new features and parts of the project and making everything work together in the end. 

The difficult part of the project is still too keep up with the AI. So much code gets produced in short amounts of time. The structure of the code is understandable from the explanations the AI gived after evey change but understanding details are complicated. The teamwork part also adds a difficulty with understanding another persons code as the same time. The LLM model easily scans trough what the other group memmber has added since last time and can keep working, while I need time to understand the different parts.
